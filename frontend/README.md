# Frontend - NFC Attendance Tracker

## Overview
Next.js (App Router) web application for NFC Attendance Tracker.

## Technology Stack
- **Framework:** Next.js
- **UI:** React, Tailwind CSS
- **HTTP Client:** Axios
- **Language:** JavaScript

## Available Routes (Initial Setup)
- `/` - Home / Landing Placeholder
- `/login` - Login Page Placeholder
- `/admin/dashboard` - Admin Dashboard Placeholder
- `/teacher/dashboard` - Teacher Dashboard Placeholder
- `/teacher/attendance` - Teacher Attendance Placeholder
- `/teacher/courses` - Teacher Courses Placeholder
- `/student/dashboard` - Student Dashboard Placeholder
- `/student/attendance` - Student Attendance Placeholder
- `/student/courses` - Student Courses Placeholder

## Environment Variables
- `NEXT_PUBLIC_API_URL` - Backend API base URL

## Running the Application
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
