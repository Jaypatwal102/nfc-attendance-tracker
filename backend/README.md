# Backend - NFC Attendance Tracker

## Overview
Express.js backend service for NFC Attendance Tracker application.

## Endpoints (Current Initial Setup)
- `GET /api/health` - Health check endpoint verifying backend status.

## Environment Variables
Configured in `.env`:
- `PORT` - Port number for the server (default: 5000)
- `MONGODB_URI` - MongoDB connection string (placeholder)
- `JWT_SECRET` - JWT signing secret (placeholder)

## Running the Backend
```bash
# Install dependencies
npm install

# Start in development mode
npm run dev

# Start in production mode
npm start
```
